# Partner Lab 2 - Flipping Cards

## Description
This SwiftUI project consists of a grid of cards. When the card is clicked, it will flip. When the card is face up, a country's flag will be displayed. When the card is face down, a generic flag symbol will be overlayed. On the board, there are two copies of every flag.
